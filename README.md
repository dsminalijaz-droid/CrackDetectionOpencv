# Crack Detection Using OpenCV

A full-stack web application built with **Django** and **OpenCV** that detects cracks in civil structures (walls, concrete, roads, bridges) from uploaded images.

## Features
- Upload an image of a structure through a web interface
- Image processing with OpenCV (grayscale, thresholding, edge/contour detection)
- Automatically classifies the image as **crack** or **no crack**
- Shows the original and the processed result side by side
- Sample test images included (Positive / Negative)

## Tech Stack
- Python 3
- Django
- OpenCV (`opencv-python`)
- NumPy
- HTML / CSS (Django templates)
- SQLite
